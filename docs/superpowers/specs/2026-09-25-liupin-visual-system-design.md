# 留频街全站视觉设计

## 范围

按用户补充，保留页面布局与内容，只统一颜色、字体、图标、图片呈现、阴影、圆角、渐变、动效和组件反馈。现行首页背景、v5 立绘及《留频街：世界观与主题设计指南》是视觉依据。首页人物位置 `(320,40)`、宽度 `820px` 和全部面板坐标保持不动。

首页强调工程师、AI 协作者与计算景片；内容页像这间工坊里的公开记录。使用旧白硬质外壳、石墨面板、灰紫织物和铜色连接的颜色关系。正文不叠纹理，不增加虚构状态、编号或故事操作名。

## 颜色与材质

深色：背景 `#17151d`，面板 `#211e29`，抬高面 `#2c2735`，正文 `#e9e4dc`，标题 `#f5f0e8`，辅助字 `#b9b0c2`，琥珀强调 `#f3bb62`，青色链接 `#84d4c6`，铜色边缘 `#b58c65`。

浅色：背景 `#f0ece4`，面板 `#faf8f3`，抬高面 `#e8e2d8`，正文与标题 `#322d38`，辅助字 `#655a6b`，深琥珀强调 `#755226`，深青链接 `#266f69`，铜色边缘 `#856143`。

沿用现有 --color-* token，并补充 --color-heading、--color-link、--color-on-accent、--color-copper、--color-line-strong、--color-accent-soft、--color-inset、--surface-sheen、--shadow-inset、--radius-control、--duration-fast、--duration-normal、--ease-out。各组件消费同一组 token。大面板圆角 8px、控件 5px；保留唱片、等级、头像和日月的圆形语义。接缝与细光只出现在边缘，使用有方向的短阴影和极弱的漆面反射。

## 字体和图形

中文沿用清楚的系统无衬线，IBM Plex Mono 用于代码、参数和时间。正文 17px、行高 1.85；控件与辅助信息 13–15px；标题 600–700 字重。替换硬编码纯白标题，确保浅色模式可读。

保留现有 SVG 图标系统，统一轮廓粗细和前景色；不引入只为少量图标服务的框架。真实文章题图与正文图片不替换。普通 Hero 复用本地工坊背景的克制裁切，保留 240/200px 高度。默认封面可改为原创计算基板的抽象几何图形，不复制 Pinterest 资产。

## 动效

使用现有 Astro、CSS 与 Web Animations API。按压约 100ms、悬停约 160ms、菜单及搜索约 200ms；位移在 1–4px。博客卡片入场保留现有结构，缩短远距离飞入，改为近处轻移和透明度变化。主题切换保留现有日夜、猫和生命周期，只统一色彩；播放器保留单一 Audio、跨页节点持久化和折叠规则。

减少动态效果时直接显示最终状态；不新增扫描线、自动视差、持续闪烁、开机等待或全站循环动效。首页透视平面与子卡片不可叠加改变几何的 transform。

## 参考与素材

Pinterest 检索尝试：retrofuturistic workstation、industrial interface design、sci-fi maintenance terminal、ceramic metal material。匿名搜索被登录界面阻挡，未采用不可核验的 Pin。用户没有指定画板，继续以已有原创素材与设定为准。UI UX Pro Max 通用复古未来结果偏霓虹，不用于本项目配色；只采用减弱动态效果与键盘操作等适用规则。

本轮没有必需的新生图素材。复用工坊背景、v5 人物和既有文章题图；边缘漆面、凹槽、接缝及抽象封面由 CSS/SVG 完成。后续可选素材是小幅材质纹理和空状态专用静物插画，不能盖住文字或冒充真实内容。

## 验收

检查首页、博客中心、文章列表、文章详情、关于、空状态、搜索、菜单、播放器与主题切换。覆盖深浅主题、桌面与手机、键盘和减少动态效果。保留路由、Giscus pathname、文章内容与加锁保护；不增加远程来源或放宽 CSP。运行 Astro 检查、单元测试、相关浏览器测试、构建和保护审计，人工检查之后才更新涉及的视觉基线。

## 实施与验证记录

已完成公共配色、字体、图标、默认封面、普通 Hero、内容面板、搜索、播放器及主题过场的视觉统一。页面网格、路由、首页人物位置和投影参数保持原值。主题过场保留日月与猫的原有形状和时序；搜索与博客入场采用短距离反馈。未增加依赖或生成新的位图。

Astro 检查零错误、警告与提示；326 项单元测试通过。113 项相关浏览器检查首轮通过 111 项：一项仍查找首页旧主导航，已按现行首页入口修正；另一项发现新导航边线使手机菜单多出 1px，高度问题改用内边线解决。两项失败及两项相关对比度检查均已复验通过。原有旧分页、已移除统计卡的测试未纳入本轮，未宣称完整端到端套件通过。

独立复查发现的浅色辅助字对比度、浅色主题下首页播放器 hover 对比度均已修正。最弱搜索辅助字对比度为 4.87:1，首页播放按钮 hover 图标为 11.88:1。9 个深浅主题与视口组合无横向溢出；普通 Hero 图片成功解码，高度仍为 240/200px。证据位于 `reports/liupin-ui-visual-check.json` 和 `reports/liupin-ui-*.png`。
