# 删除全站页脚设计

> 历史说明：本文记录的是移除旧版内容型页脚的方案。当前站点已按 `2026-09-03-compact-legal-footer-design.md` 恢复极简法律页脚。

## 背景

现有页脚包含站点身份、随机文章、最近更新、社交链接和版权信息。页面底部信息过多，本次删除整个页脚，不保留精简版本。

## 改动范围

- 从全局布局中移除 `SiteFooter`，让所有页面停止渲染 `<footer data-site-footer>`。
- 删除 `SiteFooter.astro` 及其中的文章读取、随机排序和页脚样式。
- 删除随机文章与最近更新的旧测试，新增全站页脚不再渲染的回归断言。
- 根据构建结果核对站内链接统计；只有实际总数改变时才更新固定值。

## 不改内容

- 不改正文、路由、导航、社交链接配置或其他页面组件。
- 不处理当前工作区中其他会话留下的修改。
- 不改旧 URL、Giscus pathname 或静态输出方式。

## 验证

先让回归测试因页脚仍存在而失败，再删除实现并运行相关测试。随后执行类型检查、构建和站点检查。视觉基线若只因页脚消失而变化，再更新受影响的截图。
