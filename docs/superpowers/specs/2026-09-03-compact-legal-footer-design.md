# 极简法律页脚设计

## 目的

给全站补回一条低调的法律信息栏，不恢复旧页脚的头像、简介和文章列表。

## 显示内容

页脚默认只有一行：

`© 2025–当前年份 Hatrix · 保留所有权利`

`/third-party-notices.txt` 继续随站点发布，但不在页脚显示入口。仓库目前没有根级 `LICENSE`，README 也声明站点源码与文章未另行授予开源许可，因此不显示 MIT、GPL 等项目许可证。

## 备案信息

`src/config/site.ts` 增加 `filings` 数组，页脚只渲染数组中实际存在的备案链接。当前没有查到可信的备案编号，数组保持为空，页面不显示 ICP 或公安备案占位符。

工信部现行规则适用于在中国境内提供的非经营性互联网信息服务。取得备案号后，应在主页底部中央标明编号并链接备案系统：<https://www.miit.gov.cn/gyhxxhb/jgsj/cyzcyfgs/bmgz/xxtxl/art/2024/art_84a0cfa0ebd049bbbe751dca9a008e56.html>。本站当前由 GitHub Pages 托管；如果以后迁移到中国境内接入服务商，应在迁移前确认 ICP 和公安备案要求。

## 视觉

页脚使用语义化 `footer`，只有淡色顶边线和居中的小号文字。当前内容不生成链接；以后配置真实备案信息时，备案链接继承弱化颜色，悬停时再使用强调色。窄屏允许自然换行，不设置固定高度。

## 验证

- 首页和分页页都应存在一个 `footer[data-site-footer]`。
- 页脚应显示版权，不应出现第三方许可链接或未配置的备案信息。
- 构建后 `/third-party-notices.txt` 仍可直接访问，站内链接总数同步到实际值。
- 更新 18 张全页视觉基线，确认页脚只占很小的底部空间。
