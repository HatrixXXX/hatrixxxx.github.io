# 文章正文搜索与段落高亮设计

## 目标

搜索普通文章的正文内容。搜索结果显示命中词附近的上下文，点击后打开对应文章并定位到命中段落；段落先显示浅色背景，再在短时间内渐变回原样。

## 范围与安全边界

- `locked: true` 的文章完全不进入公开搜索索引，也不会出现在搜索结果中。
- `draft: true` 的文章继续不生成页面，也不进入索引。
- 现有文章 URL、搜索入口、MiniSearch 加载方式和 Giscus pathname 保持不变。

## 索引数据

普通文章的索引文档增加可定位的正文段落列表。搜索字段仍使用标题和正文纯文本；段落列表用于生成结果上下文和文章页定位，不包含加锁正文。

中文采用按词与连续汉字片段兼容的 tokenizer，英文、数字和代码标识符继续按单词处理。结果最多保留现有上限，避免搜索面板过长。

## 搜索结果与跳转

每条结果显示文章标题、命中词附近的一至两句上下文，并在结果中用 `<mark>` 标记命中词。结果链接携带 URL 编码后的查询参数 `q`，例如 `/posts/example/?q=矩阵`。加锁结果不渲染锁定标记，因为它们不会出现在索引中。

## 文章页定位

文章页在首次加载和 Astro 客户端导航后读取 `q`。脚本在正文中的段落、列表项和引用块中查找包含查询词的首个元素，滚动到视口中央并添加临时高亮类。高亮使用 CSS 背景色渐变动画；找不到匹配内容时不改变页面。用户开启减少动态效果时保留一次性背景提示并跳过动画。

## 验证

- 单元测试覆盖：加锁文章不进入索引、中文正文可搜索、上下文截取和关键词转义。
- E2E 测试覆盖：搜索结果命中片段、点击后的 `q` 参数、正文滚动定位、临时高亮及客户端导航。
- 执行 `corepack pnpm test:run`、`corepack pnpm check`、`corepack pnpm build`，并用本地预览手工确认普通文章和加锁文章的搜索行为。
