# 文章阅读页布局设计

## 目标

文章页改为以正文阅读为中心的布局：标题和文章元信息位于正文上方，正文右侧提供目录和按可用高度筛选的最新文章卡片。文章 frontmatter 不再保存摘要。

## 内容模型

- 从文章 schema 和 40 篇已发布文章、草稿中删除 `description`。
- 搜索索引使用标题和正文纯文本；加锁文章仍只索引公开元数据，不索引正文。
- RSS 条目不再读取文章摘要，使用站点默认描述作为 feed 描述。
- 文章页传给 `BaseLayout` 的 SEO 描述使用站点默认描述；封面仍可作为社交分享图片，但不在文章正文头部渲染。

## 页面结构

文章页结构调整为：

1. 居中的文章头部，只显示标题、发布时间、最近更新时间、字数统计和预计阅读时间。
2. 一个整体居中的阅读容器，包含正文列和右侧栏；容器最大宽度约为正文阅读宽度加 280px 侧栏，并保留页面左右空白。
3. 正文列包含 Markdown 正文、相邻文章导航和评论。
4. 右侧栏按顺序包含目录（有二级至四级标题时）和最新文章卡片。

文章封面不再作为文章页内容图片渲染，因此不会触发封面灯箱。正文中的普通图片仍保留现有 PhotoSwipe 行为。

## 右侧栏规则

- 目录为空时不渲染目录卡片，右侧栏显示最多 4 篇最新文章。
- 目录存在时，服务端根据目录项数量选择最新文章数量：短目录显示 4 篇，中等目录显示 3 或 2 篇，较长目录显示 1 篇，超过可用视口高度时不显示最新文章。
- 该选择使用稳定的目录项数量阈值和卡片高度估算，不依赖客户端脚本；右栏本身使用 `position: sticky`，滚动到顶部后固定。
- 最新文章卡片为纵向紧凑卡片，仅显示封面图和标题，不显示摘要、标签或额外统计。
- 移动端改为单列：正文之后显示目录（如有），再显示最新文章卡片；不使用 sticky。

## 样式与响应式

- 桌面端正文宽度接近现有阅读宽度，右栏宽度约 260–300px，整体不贴屏幕边缘。
- 文章头部和阅读容器保持主题变量、圆角、边框和阴影风格。
- 右栏 sticky 顶部间距与站点头部错开，并限制整体高度不超过视口；目录过长时自身滚动。
- 不引入新的运行时依赖或服务端能力。

## 测试验收

- 单元测试验证文章 schema 不接受 `description`，搜索/RSS 生成不依赖摘要。
- E2E 验证文章页不渲染封面、显示五项文章元信息、目录为空时不出现目录卡片、最新文章卡片数量随目录长度变化、桌面端整体居中和右栏 sticky、移动端无横向溢出。
- 现有正文图片灯箱测试继续通过，并增加断言确认封面不会触发灯箱。
- 运行 `corepack pnpm test:run`、`corepack pnpm check`、`corepack pnpm build`、`corepack pnpm check:site` 和相关 Playwright 测试。
