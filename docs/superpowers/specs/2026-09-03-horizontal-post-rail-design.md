# 横向文章卡片栏设计

## 目标

`/blog/` 和五个文章类型页把文章放在同一条横向卡片栏内。每篇文章仍显示题图、标题、摘要、发布日期和预计阅读时长，但卡片改为题图在上、正文信息在下。桌面端约显示三张卡片，手机端显示一张卡片的大部分，并露出下一张的一角。

首页不再列出文章，也不显示文章分页。原来的文章区域改为一个跳转入口，按钮文字为“浏览全部博客文章”，目标是 `/blog/`。作者资料卡保留，文章数量仍从已发布文章集合计算。

## 页面范围

横向卡片栏用于以下页面：

- `/blog/`
- `/blog/tech-notes/`
- `/blog/troubleshooting/`
- `/blog/life/`
- `/blog/recommendations/`
- `/blog/essays/`
- 旧分页地址 `/page/2/` 至 `/page/7/`

空类型页继续显示已有空状态，不渲染空卡片栏。旧分页地址暂时保留，避免已有链接失效；首页不再提供这些地址的入口。

只有 `/blog/` 提供视图切换。五个文章类型页和旧分页地址始终使用横向卡片栏。

## 博客视图切换

`/blog/` 默认显示横向卡片栏。文章总数旁放一个“切换到时间归档”按钮；点击后在当前页面显示按年、月分组的纵向文章列表，按钮文字改为“切换到卡片视图”。再次点击恢复卡片栏。按钮保留焦点，不刷新页面，也不改变地址。

视图选择不写入本地存储。重新载入页面或再次进入 `/blog/` 时，总是从卡片视图开始。禁用 JavaScript 时隐藏切换按钮和归档面板，只保留可以正常访问的横向卡片栏。

归档面板与现有 `/archives/` 共用一个展示组件，数据都来自 `buildArchives(posts)`。`/archives/` 的路径、文章总数和作者侧栏不变。

## 卡片和卡片栏

`PostList.astro` 仍是页面使用的统一文章列表组件，内部是可横向滚动的单行 flex 容器。容器不换行，页面本身不能因此产生横向溢出。卡片栏隐藏系统滚动条，不使用滚动吸附；滚轮和拖拽产生的位移按实际距离保留。

`/blog/` 和五个文章类型页使用宽卡片栏。1025 px 以上时，卡片栏从普通内容容器向两侧延伸，距离视口左右各 32 px。较小视口沿用页面现有边距。旧分页页继续使用普通内容宽度。

`PostCard.astro` 改为纵向卡片：

- 题图固定为 16:10 比例，使用现有 Astro 图片处理和懒加载。
- 标题、三行以内的摘要、发布日期、预计阅读时长全部保留。
- 桌面卡片宽度在 272 至 352 px 之间。1180 px 内容区约能完整显示三张。
- 768 px 以下使用 `min(84vw, 336px)`，让下一张卡片仍有一部分可见。
- 卡片使用同一条 flex 行的拉伸高度，较短摘要不会让卡片底部参差。

## 滚轮和拖拽

浏览器原生 `overflow-x: auto` 是基础能力。禁用 JavaScript 时，触控板、Shift + 滚轮、键盘和滚动条仍可使用。

增强脚本只处理两件事：

1. 指针位于卡片栏上时，把鼠标的纵向滚轮增量换成横向位移。卡片栏还能沿当前方向移动时阻止页面纵向滚动；到达首端或末端后不拦截，让页面继续纵向移动。
2. 鼠标左键按住卡片栏后可拖拽。移动超过 4 px 才视为拖拽，并取消这次拖拽末尾产生的链接点击。触摸和触控笔保持浏览器原生行为。

脚本使用文档级事件委托，不保存跨页面业务状态。这样可兼容 Astro ClientRouter：首次进入文章列表页时脚本加载一次，后续页面切换继续识别新卡片栏。

## 可访问性与动态效果

卡片栏保留 `section` 和“文章列表”标签，并可通过 Tab 聚焦。隐藏提示说明可以使用滚轮、拖拽或方向键浏览。文章标题链接仍是正常链接；题图链接继续从键盘顺序中排除，避免同一文章重复获得焦点。

拖拽期间关闭文本选择，结束后保持当前位置。`prefers-reduced-motion: reduce` 下不添加平滑滚动动画。脚本不创建轮播按钮、自动播放或位置指示点。

## 验收

- 首页没有 `article[data-post-card]` 和文章分页，存在指向 `/blog/` 的“浏览全部博客文章”链接，作者资料仍显示 40 篇文章。
- 博客总页保留 40 张卡片；非空类型页保留各自文章数量和发布时间倒序。
- 博客总页默认显示卡片视图。切换按钮能在卡片栏与纵向时间归档之间往返，按钮文字和 `aria-pressed` 同步更新。
- 类型页没有视图切换按钮。重新载入博客总页后仍从卡片视图开始；禁用 JavaScript 时不显示无效按钮。
- 桌面端卡片位于同一水平线，容器 `scrollWidth` 大于 `clientWidth`，页面根元素没有横向溢出。
- 1440 px 视口下，博客总页和非空类型页的卡片栏左右边界分别位于约 32 px 和 1408 px；滚动条不可见。
- 纵向滚轮能移动卡片栏；到达末端后继续滚动能移动页面。
- 在文章链接上小幅拖动后，卡片栏停在实际拖动位置，不吸附回卡片边界，也不会打开文章。
- 无 JavaScript 时，首页按钮和文章链接仍可访问，卡片栏保持原生横向溢出。
- 单元测试、Astro 检查、图片预检、构建、站内链接检查和 Playwright 通过；首页与博客页的视觉基线按确认后的效果更新。

## 不改动的部分

- 不改文章正文、文章元数据、`/posts/<legacySlug>/` 路径或 Giscus pathname。
- 不改归档页的公开路径和内容，也不改搜索结果、页脚文章列表、作品和歌单。
- `/archives/` 只抽取已有归档列表的标记和样式，不改变页面内容与布局。
- 不新增依赖，不改变纯静态输出。
- 不删除 `/page/2/` 至 `/page/7/`。
