# 唱片机音乐播放器设计

## 目标

将现有音乐播放器升级为横向高级唱片机卡片：左侧负责信息与控制，右侧展示带唱臂的黑胶唱片机。播放时唱片旋转、唱臂落针；暂停时唱臂抬起并停止旋转。文章详情页的播放器默认收纳在左侧，点击后拉出；关于页和关于子页保持常驻显示。

## 视觉与布局

播放器仍由 `MusicPlayer.astro` 输出单一 `<aside>`，避免引入第三方播放器组件。卡片采用深色哑光底座、细边框、内阴影和分层高光。右侧唱片机使用 CSS 渐变绘制底座、唱片同心纹、中心标签、唱臂和唱头；唱片机容器允许小幅超出卡片边界，并通过 `overflow: visible` 与阴影表现厚度。视觉状态通过 `data-playback-state` 和 `data-player-mode` 驱动。

桌面布局为左侧控制区与右侧唱片机区。文章页增加 `data-content-page` 状态：默认只显示左侧窄边把手，点击把手后以 transform/opacity 动画展开完整卡片；展开状态可由 Escape 或关闭按钮收回。关于页不使用折叠。小屏幕改为底部抽屉，唱片机缩小并保持可见，不覆盖正文主要操作区域。

## 播放行为

`music-player.ts` 保持一个可复用的 `Audio` 实例，并在 Astro 页面切换时复用播放器状态。支持上一曲、播放/暂停、下一曲，以及随机、顺序、单曲循环三种模式。音量控件为可键盘操作的 range，外观增加刻度和悬浮反馈。进度条显示当前播放时间与总时长，并支持拖拽跳转。歌单为空时只渲染视觉界面，按钮禁用且不创建 `Audio`。

播放时设置 `data-playback-state="playing"`，唱片通过 CSS animation 旋转，唱臂转入播放角度；暂停和未播放状态停止旋转并将唱臂抬起。切歌时同步曲名、艺术家和封面标签；没有封面时使用渐变唱片标签。

## 可访问性与约束

所有按钮提供中文 `aria-label`，播放按钮同步 `aria-pressed`，模式按钮同步 `aria-label` 和当前模式文字。折叠把手可用键盘激活，动画遵守 `prefers-reduced-motion`。不新增服务器、数据库或远程媒体；沿用现有 `playlist.ts` 与项目的静态输出约束。

## 验证

至少运行 TypeScript/Astro 检查、单元测试和构建；检查空歌单、播放/暂停状态、模式切换、音量持久化、文章页折叠/展开和减少动态效果样式。完成后启动本地预览并检查播放器在关于页与文章页的实际布局。
