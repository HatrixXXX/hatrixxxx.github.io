# 横向文章栏滑动阻尼设计

## 目标

博客总页和文章类型页的横向卡片栏增加连续的滑动手感：滚轮输入经过阻尼追赶，鼠标拖拽松手后按最近移动速度继续滑行并逐渐停止。卡片栏仍然不吸附到卡片边缘，用户停在什么位置就保留什么位置。

## 范围

- 修改 `src/scripts/post-rail.ts`，为每个文章栏维护独立的动画和拖拽状态。
- 必要时抽出纯运动函数到 `src/lib/`，用单元测试覆盖目标位置、速度衰减和边界钳制。
- 在 `tests/e2e/blog-index.spec.ts` 增加滚轮缓动、拖拽惯性和减少动态效果的行为检查。
- 不新增依赖，不改变文章卡片结构、路由、键盘操作和无 JavaScript 降级。

## 交互设计

### 滚轮

指针位于文章栏时，脚本沿用现有的增量换算和边界判断。当前方向仍有可滚动空间时，事件被拦截，增量累加到该栏的目标 `scrollLeft`；动画帧让实际位置逐步追赶目标位置，并在接近目标时停止。连续滚轮输入会更新同一个目标，不创建多个动画队列。

滚动到首端或末端后，朝边界外的滚轮事件不拦截，页面恢复纵向滚动。目标位置和实际位置都限制在 `[0, scrollWidth - clientWidth]` 范围内。

### 鼠标拖拽

按下鼠标左键后，超过 4 px 才进入拖拽。拖拽期间 `scrollLeft` 直接跟随指针，避免明显延迟；脚本记录最近一小段时间内的位移，用于估算松手速度。松手后启动惯性动画，速度按帧衰减，直到低于阈值或碰到首尾边界。惯性不会吸附，也不会触发拖拽结束后的链接点击。

没有超过阈值的点击不启动动画，仍按正常链接点击处理。触摸和触控笔继续使用浏览器原生行为。

### 减少动态效果

当 `prefers-reduced-motion: reduce` 生效时，滚轮直接设置最终位置，拖拽松手不启动惯性；拖拽本身仍可跟手。媒体查询变化后，正在运行的动画立即停止并清理状态。

## 实现结构

使用 `WeakMap<HTMLElement, RailMotionState>` 保存每个文章栏的运动状态，状态包括目标位置、惯性速度、动画帧句柄和最近拖拽采样。文档级事件委托继续用于兼容 Astro ClientRouter，新增的动画只操作触发事件所属的文章栏。

动画循环按时间差更新位置，并对时间差设置上限，避免切后台或调试暂停后一次跳跃过大。每次写入位置都经过边界钳制；状态归零后取消 `requestAnimationFrame`，避免空转。

保留现有 `data-dragging`、指针捕获、拖拽点击抑制和 `dragstart` 拦截逻辑。键盘事件不由脚本接管，原生方向键继续操作 `scrollLeft`。

## 验证

- 单元测试验证目标追赶、速度衰减、边界碰撞和 reduced-motion 分支。
- Playwright 验证滚轮后位置先逐步变化再稳定，拖拽松手后仍有位移且最终停止；位于边界时页面可以继续纵向滚动。
- Playwright 在 reduced-motion 上下文中验证滚轮立即到达目标、拖拽松手不产生额外惯性。
- 执行项目要求的 `test:run`、`check`、`build`、`check:site` 和相关博客 E2E；完成后启动本地预览并用 HTTP 请求确认可访问。

## 不改动的部分

- 不改变文章正文、元数据、公开 URL、Giscus pathname 或卡片布局。
- 不引入 `scroll-snap`、轮播按钮、自动播放或新的滚动库。
- 不修改首页封面、归档视图和文章页正文滚动行为。
