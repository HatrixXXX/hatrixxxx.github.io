# 首页透视布局与全站播放器

2026-09-25 按四张明日方舟首页参考图校准首页框架，并按留频街设定统一背景、人物受光和卡片配色。人物与计算景片一起缩放，入口面板叠在立绘之上。此记录替代旧首页封面的打字、箭头、拖动揭开，以及播放器作为侧栏第三张卡片的约定。

## 构图与尺寸

首页以 `1920×1080` 为设计画布。`src/pages/index.astro` 的 `leftPanels` 记录左侧四角投影，`rightPanels` 记录右侧卡片在同一个平面内的局部位置与尺寸。右侧只由 `right-plane` 父层应用一次 `projectPanel` 生成的 `matrix3d`，7 个子卡片均为 `transform:none`；文字和图标随父层一起投影，未引入 3D 运行库。

右侧分为大卡、并排双卡、收藏复合组、底部双卡四层。上层向右上抬起，中层接近水平，下层向右下展开，方向差异来自同一个平面的位置变化，不再逐卡指定旋转。左下组保持向内收窄的轻微透视。

右侧平面局部尺寸为 `930×952`，投影角依次为 `(970,120)`、`(1910,8)`、`(1910,1068)`、`(970,958)`。主要行列间隔为 12 个局部像素，收藏区内部间隔 4px。底部计划和实验场各为 `399×162`，已移除辅助空槽，两张卡片共同占满底排。时钟宽 820px，博客卡片宽 790px，右边缘对齐。左侧播放器与小卡之间、金句与底部入口之间保留约 10～14 个设计像素的间隙。

画布按有效 CSS 视口同比缩放并居中；两组内部保持固定排布。超宽屏额外用纯 CSS 平移两组，抵消画布侧面的留白，使最外侧面板距屏幕两边约为 10 个设计像素；组内没有拉伸，中央角色留白相应增加。竖屏仍留上下空白。首页无滚动，不渲染普通导航栏、页脚、Sakana 或 CursorTrail。角色容器覆盖整张设计画布，以 `overflow:hidden` 将下半身裁在画布边缘，避免人物伸进竖屏留白；图片设计坐标为 `(320,40)`，宽 `820px`，高度按原图比例计算。角色层透明且不拦截输入。窄竖屏的文字和点击区域较小，完整显示不代表移动端无障碍已通过。

## 背景场景

首页背景源图为 `src/assets/home/liupin-workshop-v5.png`，实际尺寸 `1672×941`。内置 image_gen 以当前 v5 立绘为参考，按修订后的阿岑与 AI 协作者栈的设定重画计算检修工坊。港口、维修台、放映机与转接器集中在左侧，中央为低对比灰紫墙面，右侧计算机架承接物理计算载体的设定。旧白机壳、石墨模块和铜线呼应立绘，暖灯与灰紫反射保持克制。背景不重复绘制人物或 AI 侧脸。生成提示词位于 `output/imagegen/liupin-workshop-v5.prompt.txt`。

`index.astro` 使用 Astro `getImage` 将源图输出为质量 85 的 WebP。背景放在画布的静态伪元素中，不拦截点击；普通屏幕随画布等比缩放，超宽屏向两侧扩展并居中裁切，竖屏保留深紫灰上下留白。卡片坐标和交互沿用现有实现。博客主入口使用浅色旧漆面，其余面板为紫灰，收藏区使用暗青色，琥珀色用于细线、时钟和首页播放按钮。播放器配色覆盖只在首页容器内生效。

用户在多轮迭代后明确选回 v5。当前角色源图为 `src/assets/home/hatrix-character-v5.png`，与 `output/imagegen/hatrix-character-v5.png` 原图一致，实际尺寸为 `1024×1536`，带透明通道。保留封闭头盔人物、芯片景片、铜色互连弧线、脚下平台和代表 AI 协作者栈的右上颗粒侧脸，不再套用后续迭代中的元素删减要求。源图包含完整全身；首页将整图宽度从 950px 调为 820px，并按用户预览反馈将最终位置设为 `(320,40)`。头盔和双手保持可见，AI 侧脸右缘可与入口面板相叠，部分下身和脚下基板裁在画布外，入口面板可覆盖衣摆和景片。人物原图及全部外围元素未编辑，文件 SHA-256 与选定的 v5 原图一致。Astro `Image` 输出质量 90 的透明 WebP。角色不参与键盘焦点或拦截点击，也不添加动画。其余版本保留供对照，选定图片的生成提示词位于 `output/imagegen/hatrix-character-v5.prompt.txt`。首页 3 张视觉基线已包含 v5 立绘、新背景和最终裁切位置。

链接由 `src/config/navigation.ts` 统一提供。金句减少动态效果时默认暂停自动切换，手动切换直接替换文字；离开首页时清理计时器、监听器和动画。旧 `home-cover.ts` 已删除。

等级由 `src/lib/home-level.ts` 按生日 `2002-07-29` 计算，统一使用北京时间（UTC+8）的日期，不受访问者时区影响。等级是周岁，每年 7 月 29 日零点升一级，圆环归零。进度按整天计算：距上次生日的天数除以两次生日之间的实际天数，包含闰日的年度使用 366 天。例如 2026-09-25 为 24 级，进度为 `58/365 ≈ 15.89%`。

等级在浏览器进入或返回首页时计算，并复用现有时钟更新检查跨日变化；页面恢复可见时立即刷新，日期未变时不重复改写 DOM。圆环没有过渡动画，悬停提示和辅助阅读文本提供年龄、进度及北京时间口径。无 JavaScript 时显示 `—` 和启用提示，不在静态 HTML 中写入会过期的年龄。

页面返回按钮使用固定目标：六个文章列表页返回 `/blog/`，文章详情返回所属类型页，其余页面统一返回首页。关于子页不再返回 `/about/`；归档、旧分页和 404 也提供返回首页按钮。

非首页的顶部导航按视口居中，依次显示首页、博客文章、作品橱窗、书签、软件、装备、计划、实验场、友链、留言板。搜索和主题按钮放右侧，管理员退出按钮放左侧；仅博客保留横向二级菜单。宽度小于 `1200px` 时使用折叠菜单，入口顺序相同。关于我仍保留在首页卡片中。展开手机菜单时，菜单层级高于返回按钮和播放器。

## 播放器与侧栏

`MusicPlayer.astro` 支持 `home` 和 `dock` 两种模式。首页播放器填满左下 `380×195` 局部卡片，不能折叠；其他页面由 `BaseLayout.astro` 挂载，默认固定在左侧并折叠，只露出半张唱片。点击唱片可展开，点击标题、空白或收起按钮可折叠；播放、进度和音量控件独立处理。

全站每页只有一个播放器，通过 `transition:persist="music-player"` 保留 DOM 和 Audio。`music-player.ts` 在客户端导航后按当前路径更新模式，避免持久化节点继续使用旧页面属性。空歌单不创建 Audio；减少动态效果时停用唱片旋转和滑动过渡。

播放器不再属于 `SidebarStack`。该组件承载作者资料，统计由页面配置；当前关于页及其子页关闭统计卡，文章页另用目录和最近文章侧栏。
