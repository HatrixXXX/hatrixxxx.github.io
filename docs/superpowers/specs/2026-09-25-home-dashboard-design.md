# 首页透视布局与全站播放器

2026-09-25 按用户标注的参考图重建首页框架。当前只实现排布和功能入口，角色立绘留空，颜色与纹理后续再设计。此记录替代旧首页封面的打字、箭头、拖动揭开，以及播放器作为侧栏第三张卡片的约定。

## 构图与尺寸

首页以 `1920×1080` 为设计画布。`src/pages/index.astro` 记录每块卡片的局部尺寸和左上、右上、右下、左下四角；`HomePanel.astro` 调用 `src/lib/home-projection.ts` 中的 `projectPanel`，把局部矩形映射为 CSS `matrix3d` 投影。左右卡片保留参考图朝向中央的透视关系，未引入 3D 运行库。

画布按有效 CSS 视口的宽高同比缩小或放大，完整居中显示。窗口尺寸和浏览器缩放变化时不重排卡片；竖屏留上下空白，超宽屏留左右空白。首页固定在视口内，没有滚动，也不渲染普通导航栏、页脚、Sakana 或 CursorTrail。中央角色区域不拦截输入，暂时不放替代素材。

## 入口与交互

| 区域 | 当前行为 |
| --- | --- |
| 左上搜索 | 首页唯一搜索按钮，复用站内搜索 |
| 左中 Hatrix | 站名字样 |
| 左下金句 | 使用 `src/data/home-quotes.ts` 的两条测试语料，每 15 秒轮换；双击或键盘 Enter/空格立即切换，按钮可暂停 |
| 左下播放器及右侧两按钮 | 播放器常驻；友链进入 `/about/friends/`，留言板进入 `/guestbook/` |
| 右上时钟 | 辉光管样式，每秒按本地时间显示 `YYYY/MM/DD HH:mm:ss` |
| 博客文章 | 普通链接直接进入 `/blog/`，再由该页进入“全部文章”和五种文章类型；无 JavaScript 时仍可导航 |
| 作品橱窗、关于我 | 分别进入 `/projects/`、`/about/` |
| 收藏推荐 | 标题无跳转；书签、软件、装备分别进入 `/about/bookmarks/`、`/about/tools/`、`/about/gear/` |
| 计划、实验场 | 分别进入 `/plans/`、`/lab/`，目前显示空状态 |

链接由 `src/config/navigation.ts` 统一提供。金句减少动态效果时默认暂停自动切换，手动切换直接替换文字；离开首页时清理计时器、监听器和动画。旧 `home-cover.ts` 已删除。

页面返回按钮使用固定目标：六个文章列表页返回 `/blog/`，文章详情返回所属类型页，其余页面统一返回首页。关于子页不再返回 `/about/`；归档、旧分页和 404 也提供返回首页按钮。

非首页的顶部导航按视口居中，依次显示首页、博客文章、作品橱窗、书签、软件、装备、计划、实验场、友链、留言板。搜索和主题按钮放右侧，管理员退出按钮放左侧；仅博客保留横向二级菜单。宽度小于 `1200px` 时使用折叠菜单，入口顺序相同。关于我仍保留在首页卡片中。展开手机菜单时，菜单层级高于返回按钮和播放器。

## 播放器与侧栏

`MusicPlayer.astro` 支持 `home` 和 `dock` 两种模式。首页播放器填满左下 `385×198` 局部卡片，不能折叠；其他页面由 `BaseLayout.astro` 挂载，默认固定在左侧并折叠，只露出半张唱片。点击唱片可展开，点击标题、空白或收起按钮可折叠；播放、进度和音量控件独立处理。

全站每页只有一个播放器，通过 `transition:persist="music-player"` 保留 DOM 和 Audio。`music-player.ts` 在客户端导航后按当前路径更新模式，避免持久化节点继续使用旧页面属性。空歌单不创建 Audio；减少动态效果时停用唱片旋转和滑动过渡。

播放器不再属于 `SidebarStack`。该组件承载作者资料，统计由页面配置；当前关于页及其子页关闭统计卡，文章页另用目录和最近文章侧栏。
