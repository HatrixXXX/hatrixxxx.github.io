# 关于页与文章页侧栏设计

## 目标

关于页和文章正文页新增一组共享侧栏，由作者资料、站点统计和音乐播放器三张卡片组成。首页、博客列表、归档、作品、留言板和其他页面不显示这组卡片。

视觉参考只用于确定信息层级和动效方向：资料卡参考云游君文章页的左栏，时钟参考 Kuroha 博客的点阵时钟。实现沿用本站现有色板、圆角和阴影，不复制参考站源码、文案或素材。

## 页面范围

显示侧栏的路由：

- `/about/`
- `/about/<section>/`
- `/posts/<legacySlug>/`

不显示侧栏的路由包括首页 `/`、分页 `/page/<page>/`、博客列表、文章类型页、归档、作品、留言板和 404 页面。

现有全局音乐播放器从 `BaseLayout` 移除，改为侧栏第三张卡片。因此音乐播放器也只出现在上述目标路由。

## 组件边界

新增 `SidebarStack.astro` 作为共享边界，顺序固定为：

1. `ProfileSidebar.astro`
2. `SiteStats.astro`
3. `MusicPlayer.astro`

`SidebarStack` 接收已发布文章集合，负责计算构建期统计数据并传给子组件。页面只决定侧栏放在哪里，不重复统计和卡片结构。

当前 `ProfileSidebar` 的文章计数迁移到 `SiteStats`。资料卡只负责头像、站名、标语和社交入口。

## 站点统计

统计卡显示六项数据：

- 文章数：已发布 `posts` collection 的条目数。
- 总字数：对每篇已发布文章的 `body` 使用项目现有 `reading-time` 规则计数，再求和。这样中文、英文和数字的口径与文章阅读时长保持一致。
- 运行天数：以 `2025-02-17 00:00:00 Asia/Shanghai` 为起点，按自然日计算，起始日记为第 1 天。
- 访客量：Vercount 的全站独立访客 `site_uv`。
- 最后更新时间：所有已发布文章中最大的 `updatedDate ?? pubDate`，格式为 `YYYY-MM-DD`。
- 当前时间：浏览器所在设备的本地时间，格式为 `HH:mm:ss`。无脚本时保留构建时文本，不让卡片出现空白。

文章数、总字数和最后更新时间在 Astro 构建时生成。运行天数和当前时间由浏览器更新，页面跨午夜打开时运行天数也会变化。

## Vercount

全局布局在生产环境加载 `https://events.vercount.one/js`，这样没有侧栏的页面也会计入全站访客。开发预览和测试环境不发送统计请求。

统计卡只读取 Vercount 写入的 `site_uv`。加载完成前显示 `—`；脚本被广告拦截器、内容安全策略或网络阻断时继续显示 `—`，不影响其他统计项和正文。页面不保存 API Key，也不增加服务器、数据库或 Worker。

Vercount 统计从功能上线后开始累计。以后若需要调整历史初始值，可在 Vercount 完成域名验证后操作，这不属于本次代码改动。

## 点阵时钟

点阵时钟使用本站自己的 Canvas 客户端脚本。脚本保存十个数字和冒号的点阵模板，根据卡片宽度与设备像素比绘制，不使用 Kuroha 的代码或固定尺寸。

每秒变化时，只为发生变化的旧数字生成彩色粒子。粒子带有轻微横向速度和向下加速度，离开画布后立即删除。粒子数量设置上限，标签页隐藏时暂停绘制，恢复可见后直接同步当前时间，避免后台积累动画。

启用 `prefers-reduced-motion: reduce` 时不生成粒子，只重绘新时间。Canvas 对辅助技术隐藏，旁边保留一个可读取的 `<time>` 文本，但不使用 `aria-live`，避免屏幕阅读器每秒播报。

## 音乐播放器

音乐播放器改成普通侧栏卡片，不再使用固定定位。保留当前数据结构、空歌单提示、音量偏好和 `transition:persist="music-player"`。

歌单为空时不得创建 `Audio`，按钮保持禁用。歌单以后有内容时，卡片仍使用当前标题、歌手、上一首、播放、下一首、音量和进度结构；本次不添加演示歌曲，也不扩展播放逻辑。

## 布局

文章页在宽屏下使用三栏：左侧卡片组、中间正文、右侧目录。文章区域使用独立的较宽容器，不修改其他页面的全局 `--content-width`。正文可用宽度不得小于现有阅读宽度的合理范围。

关于页在宽屏下使用两栏：左侧卡片组，右侧关于内容。根关于页移除重复的头像和社交链接，只保留介绍文字；关于子页保留现有标题和空状态。

宽度不足时改为单栏。文章页依次显示移动目录、正文和侧栏，避免读者先滚过三张卡片才能看到文章。关于页先显示正文，再显示侧栏。侧栏只在宽度和视口高度都足够时吸顶，较矮窗口使用普通文档流，防止播放器卡片被遮住。

首页删除旧资料卡后，现有博客入口卡片占满内容区。分页不恢复文章列表或其他旧首页内容。

## 测试与验收

单元测试覆盖统计函数：

- 只统计已发布文章输入。
- `reading-time` 字数求和正确。
- 最后更新时间优先使用 `updatedDate`。
- 运行天数在起始日、跨日和上海时区边界上正确。

Playwright 覆盖：

- 首页、博客列表和归档没有侧栏与音乐播放器。
- 根关于页、关于子页和文章正文页各有一组侧栏，三张卡片顺序正确。
- 社交链接、外部链接属性和微信待补充状态正确。
- Vercount 成功时显示 UV，失败时显示 `—` 且正文可用。
- 点阵时钟每秒更新时间，减少动态效果时不生成粒子。
- 空歌单不创建音频对象或媒体请求。
- 宽屏文章页为三栏，移动端无水平溢出且正文排在侧栏之前。
- 主题切换、Astro 客户端导航、文章目录和 Giscus 保持现有行为。

完成前运行项目规定的单元测试、类型检查、图片检查、构建、构建产物检查和 Playwright 测试。全局播放器移除会影响现有 18 张视觉基线：首页移除旧资料卡和播放器，文章页加入共享侧栏，博客、归档、作品和 404 移除播放器。关于页没有既有基线，另行检查桌面和手机截图。

## 不在范围内

- 不接入新的服务器、数据库、Cloudflare Worker 或私有统计 API。
- 不补写微信地址，不猜测 QQ 音乐用户参数。
- 不添加歌曲、示例作品或新的文章内容。
- 不修改文章正文、旧文章路径、Giscus pathname 映射和站点导航结构。
