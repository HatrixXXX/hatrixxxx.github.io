# 删除文章分类与标签

> 历史说明：本文档中的五项旧导航说明已由 `2026-09-03-navigation-content-hubs-design.md` 取代；禁止恢复旧分类和标签 taxonomy 的约束仍然有效。

## 背景

站点当前把分类和标签写入文章 frontmatter，并用于内容校验、文章索引、页面展示、搜索和独立归档路由。现在不再需要这套功能。本次改动将它从当前架构中删除，不保留隐藏字段或兼容页面。

## 范围

- 删除已发布文章和草稿 frontmatter 中的 `category`、`tags`。
- 删除文章 schema、TypeScript 类型和站点配置中的分类、标签定义。
- 删除分类与标签的聚合函数、URL helper 和搜索字段。
- 删除 `/categories/`、`/categories/**`、`/tags/`、`/tags/**` 静态路由。旧地址返回 404，不做重定向。
- 从主导航、文章卡片、文章页、面包屑、作者侧栏和搜索界面移除分类、标签信息。
- 更新单元测试、E2E 测试、视觉测试、构建检查和当前项目文档。

Giscus 的 `category` 与 `categoryId` 是评论区配置，不属于文章分类，继续保留。文章正文、`legacySlug`、系列、归档、搜索和相邻文章功能不变。

## 页面行为

主导航保留首页、文章、归档、作品和关于。作者侧栏只显示文章总数。文章卡片从标题开始，不再显示分类。文章面包屑改为“首页 / 文章标题”，正文末尾不再显示标签。

搜索索引只包含文章 ID、URL、标题、摘要和正文文本。搜索结果副标题显示文章摘要，搜索框提示改为“输入标题、摘要或正文关键词”。

## 数据与构建

文章集合不再接受或生成分类、标签字段。分类和标签路由从 Astro 构建、sitemap 和站内链接检查中消失，文章公开路径保持不变。

构建完成后，以新产物重新统计 HTML、sitemap URL 和站内链接数量，再更新固定断言，不预设最终数值。

## 测试与文档

单元测试删除分类常量、taxonomy 聚合和 taxonomy URL 断言，并验证搜索文档不含分类、标签字段。E2E 测试删除分类、标签页面的正向检查，增加幸存页面不再链接这两类路由的断言。删除对应的六张视觉基线，重新核对并更新受公共导航、侧栏、文章卡片和文章布局影响的其余基线。

README 和 AGENTS 只描述删除后的现行结构。旧的重建设计与实施计划保留为历史记录，并在开头注明其中的分类、标签设计已由本文档废止。

## 验收条件

- 源码、文章元数据和构建产物不再提供文章分类或标签功能。
- `/categories/**` 和 `/tags/**` 不再生成页面，站内不存在指向它们的链接。
- Giscus 配置、40 条 `/posts/<legacySlug>/` 路径和文章正文保持不变。
- 单元测试、类型检查、构建检查和 E2E 测试通过。
- 本地开发预览可正常访问。
