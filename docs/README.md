## 当前实现

站点采用 Astro 静态输出。已发布文章保存在私有内容仓库，所有通过校验的文章都会生成页面。加锁文章只公开元数据、封面和解锁外壳，正文与正文图片输出密文，也不进入公开搜索索引。

首页使用 1920×1080 透视画布，随有效视口等比缩放，中央展示 v5 立绘及计算景片。右侧卡片共用一个投影平面；超宽屏上左右两组向视口边缘平移，组内排布不变。搜索、金句、辉光管时钟和各页面入口已接入。首页博客卡片直接进入 `/blogs/`，文章详情也返回该列表；其余页面返回首页。

文章页的二至四级目录始终完整展开。桌面宽屏下，目录和最近文章组成的侧栏只在能整体放入可用视口时固定；否则使用页面滚动。文章页还提供右下角返回顶部按钮。

非首页顶部导航按视口居中，顺序为首页、博客文章、作品橱窗、关于我、随笔、收藏夹、工具箱、计划、资讯、友链、留言板、实验场。小于 1200px 时使用同顺序的折叠菜单，博客不提供类型二级入口。主导航栏目页不显示 Hero 主标题或副标题栏，桌面端主要内容从导航下约 16px 开始，作品橱窗从导航下展开并可纵向滚动；博客卡片基本占满导航栏之外的视口高度。作品橱窗用三层机械平台陈列 13 个玻璃罐，点击可放大查看图片和介绍。工具箱按用途使用不同荧光边框，桌面端每行 9 张图标卡片，窄屏依次调整为 8、6、3 列。留言板加载 Twikoo 评论。播放器在首页常驻，在其他页面折叠为左侧半张唱片，客户端导航保持播放。

页面、站内链接、远程图片和测试数量都从当前内容与代码派生，以本地命令输出和测试源码为准，不在文档中维护副本。
