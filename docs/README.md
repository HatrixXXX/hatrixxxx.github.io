## 当前实现

站点采用 Astro 静态输出。私有内容仓库有 41 篇文章，所有通过校验的文章都会生成页面。加锁文章只公开元数据、封面和解锁外壳，正文与正文图片输出密文，也不进入公开搜索索引。

首页使用 1920×1080 透视画布，随有效视口等比缩放，中央角色留空。搜索、金句、辉光管时钟和各页面入口已接入。首页博客卡片直接进入 `/blog/`；六个文章列表页返回 `/blog/`，文章详情返回所属类型页，其余页面返回首页。

非首页顶部导航按视口居中，顺序为首页、博客文章、作品橱窗、书签、软件、装备、计划、实验场、友链、留言板。小于 1200px 时使用折叠菜单，仅博客保留二级入口，关于我保留首页卡片。播放器在首页常驻，在其他页面折叠为左侧半张唱片，客户端导航保持播放。

完整构建生成 71 个 HTML 页面，远程图片清单包含 277 个 URL，站内链接检查清单为 3976 条。测试数量与验证范围见项目 README。
